# Download para Windows x64

[Baixar o conversor DWF 3D para DWG / DXF (ZIP, 56 MB)](https://github.com/mrcorzf/DWF-TO-DWG/raw/refs/heads/downloads/windows-x64/downloads/DWF-3D-para-DWG-Windows-x64.zip)

Extraia o ZIP e execute `DWF-3D/dwf3d.exe`. Mantenha `dwgwriter.exe` na
mesma pasta. Selecione o DWF; o DWG sera criado ao lado do arquivo original.
Nao sobrescreve arquivos existentes.

Windows 10 (1903 ou posterior) / Windows 11, x64. Fontes e licencas
acompanham o pacote. Os testes de conversao passaram no Linux; a execucao
dos executaveis no Windows ainda precisa ser validada nesse sistema.
